# Voyage Concierge

End-to-end agentic AI walkthrough: how a travel company can discover anonymous social signals, nurture them with personalized multi-channel campaigns, and convert them into bookings — all without manual marketer effort.

## 🎬 Live Demo

**[View the interactive walkthrough →](https://anant2510.github.io/Voyage-Concierge/)**

Follow Sarah Mitchell, a marketing director from Austin, as she goes from anonymous Instagram post to confirmed Banff booking in 6 days. Watch the Customer Data Platform populate live as you progress through 11 steps.

## What's Inside

The walkthrough demonstrates how 6 systems work together:

1. **Lead Discovery agent** — Scans public social posts via Meta Graph API, Reddit API, and licensed listening tools (Brandwatch, Sprinklr)
2. **LLM agent** — Scores intent, extracts personalization hooks, generates all message content
3. **Customer Data Platform** — Stitches identity across email, mobile, social, and behavioral history using LiveRamp / Experian
4. **Journey Orchestrator** — Triggers escalations when engagement crosses thresholds, suppresses channels post-conversion
5. **Nurturing agent** — Designs and deploys multi-channel campaigns (email, SMS, Instagram DM, retargeting)
6. **Acquisition agent** — Live booking conversation with tool use (flights, hotels, weather, payments)
